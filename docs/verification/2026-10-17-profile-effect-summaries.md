# Draft effects and transformation summaries

The profile canvas summarizes authored controller publication choices, hiding
requests and virtual controllers. It labels these as draft requests and preserves
the separate applied revision. Built-in processing summaries expose timing,
polarity, thresholds, axis curves and macro steps in both the editor and the
immutable native topology. UTF-8 previews stay below 256 bytes; full parameters
remain in the inspector and script source remains private.

Local validation on frozen sources: 49 focused frontend tests and 85 workspace
tests passed; both Svelte checks reported zero errors/warnings and the private
production Vite build passed. Canvas and processing source coverage gates passed.
All six native topology tests passed, including parameter changes and bounded
Unicode summaries. Source-stamped native topology coverage is 226/255 production
lines (88.63%), above the existing 71% gate.

Evidence is retained in `.research/p9-ui-effects`, including the frozen manifest,
individual test/check/build logs and `native-topology-coverage`. These read-only
summaries do not establish physical device or game delivery qualification.
