# Native profile host integration

The Manager now owns the journaled coordinator and a native health worker.
Explicit Apply captures an exact saved revision through one-use read-only
preparation, then acquires native sources, waits for real baselines and arms the
shared typed reducer. Default needs no optional driver, hiding or game provider.
Editor reads and saves remain separate from activation.

The concrete host consumes the existing HID history, isolated script workers,
virtual-controller feeder/journal, and native game adapters. Game samples reach
the reducer before timers and script callbacks. Simulator effects require the
current native invocation token, exact ordered action tuple, applied owner and
verified game context. Lost context withdraws its reader scope and dependent
source values; ordinary hardware branches continue. Failed effects are not
queued for retry. A stopped outgoing reader cannot withdraw a newer reader.

Typed private USB/CAN access shares the public configuration writer gate.
Readable physical source acquisition, owned runtime overrides, companion
ownership and visibility integration remain subsequent units; admission reports
unsupported resources explicitly. Existing unqualified virtual-output, script,
visibility and physical-device capabilities are not enabled by this integration.

Verification combines native coordinator/adapters and actual Manager admission
tests. Source-stamped coverage evidence and test counts are recorded in
`2026-10-17-profile-preflight-admission.md`; game transport/decoder evidence is
recorded separately in `2026-10-17-unified-profile-game-adapters.md`.
The full copied Windows native suite completed with 564 passing, three ignored
and three Windows credential-protection failures under the sandbox account.
Those same three tests then passed with normal Windows user access: 567 passing
tests across the full run and focused environment-correct rerun. The retained
full log is `.research/main-native-2026-10-17/tests.log`.
This host wiring is implementation progress for P4, not complete feature or
hardware/simulator acceptance.
