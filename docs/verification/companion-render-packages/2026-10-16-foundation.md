## Delivered boundaries

- Waveshare recycles a framebuffer only after all existing presentation fences succeed, then copies the complete presented image into it. The alternating-disjoint-update regression fails with the old behavior and passes with the fix; errors/timeouts never copy or reuse a buffer.
- Both board profiles include bounded allocation-free diagnostic counters, heap/stack sampling and a stopped-input capture command. [Physical evidence](milestone-0-baseline.md) records exact installed application hashes and initial complete-redraw captures. Full active USB/WSS qualification is pending.
- `@opensimgear/companion-renderer` supplies strict canonical manifests, immutable content/profile identities, ABI 1 object packing and content validation, conservative expression/type proofs, reachable spatial coverage and declared resource admission. Its two profiles are proposed caps rather than measured certification.
- TypeScript-generated byte fixtures are read independently in Rust and portable C. Rust/C structural success does not validate semantic record authority, authorize a package or create a session. The native production service has no new content/session endpoint.
- The portable C expression evaluator implements all sixteen ABI operations with an eight-scalar stack, checked Q16.16 conversion/arithmetic, bounded instructions/lookups, immutable read callbacks and no heap. Sixty-three independent expected-value vectors exercise both TS and C. Invalid results never become input events.
- Designer schema 3 has an explicit authoring/validation/migration/publication path. It separates logical ownership and typed feedback contracts from immutable recipe references, provides target diagnostics, and distinguishes visual from semantic changes. Existing schema 2 fixtures, publication identities and live consumers remain on their existing path.

## Remaining acceptance work

R0 still needs active USB and WSS workloads, reconnect/TLS headroom, the mixed-input soak, visual observation and a measured transfer-batching decision. Current full-redraw results do not qualify full-screen 5/10 Hz.

R1/R2 need explicit local-state variable and timeline lifecycle semantics before freezing the draft ABI. Resolved recipe/source lowering, image/font conversion, C scene record admission, clipping/composition, damage scheduling, source-authority comparison and matching raster vectors are not implemented.

R3 onward still require authenticated v2 preparation/reads/open, durable inactive content slots and interruption recovery, one-time partition installation, native cache/assignment integration, designer/DOM catalog rendering and qualified advanced interactions. Both boards must then demonstrate A-to-B package changes on an unchanged engine image, variable-only steady traffic and physical recovery/quality/timing evidence. No milestone or physical proof of concept is marked complete by this checkpoint.
