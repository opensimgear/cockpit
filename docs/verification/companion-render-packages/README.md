# Historical render-package evidence

PR [#77](https://github.com/opensimgear/cockpit/pull/77) is superseded by the shared widget/LVGL work merged in [#139](https://github.com/opensimgear/cockpit/pull/139).

Start with the [22 October supersession audit](2026-10-22-supersession.md) for the preserved framebuffer fix, current equivalents and unfinished requirements.

The fourteen reports dated 16–17 October, including the five files under `evidence/`, are byte-for-byte copies from commit `f2c9147b863a1aab7de1dd9026bf54e5430b16c4`. Their firmware hashes, source identities, local paths, commands, successes and failures describe the old custom engine. They do not qualify the current LVGL firmware. No physical measurements were repeated as part of this archive.
