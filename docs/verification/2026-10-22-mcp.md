## Reproduction

Run native checks in a normal Windows process with loopback and symlink access;
the restricted sandbox cannot reproduce every native test faithfully. Use a
worktree-local temporary directory for atomic-file tests.

```powershell
Set-Location C:\Users\ivang\_pws\opensimgear\cockpit-mcp-119
New-Item -ItemType Directory -Force .research/native-temp | Out-Null
$env:TEMP = (Resolve-Path .research/native-temp).Path
$env:TMP = $env:TEMP
$env:CARGO_TARGET_DIR = 'C:\Users\ivang\_pws\opensimgear\cockpit\src-tauri\target'
cargo test --manifest-path src-tauri/Cargo.toml --lib -- --test-threads=4
cargo test --manifest-path src-tauri/Cargo.toml --lib mcp -- --nocapture --test-threads=4
cargo test --manifest-path crates/profiles/Cargo.toml service:: --offline
cargo test --manifest-path src-tauri/Cargo.toml --lib local_settings_ --offline -- --nocapture
cargo test --manifest-path src-tauri/Cargo.toml --lib draft_save_preserves_the_exact_active_owner -- --nocapture
cargo test --manifest-path src-tauri/Cargo.toml --lib profile_desktop_settings::tests:: -- --nocapture
pnpm mcp:test
pnpm check
pnpm transport:test
pnpm ui:build
```

The local run used `.research/dev/tauri.json` with the isolated identifier,
`build.devUrl` set to `http://127.0.0.1:1449`, a matching `app.security.devCsp`,
and `build.beforeDevCommand` set to
`pnpm exec vite --host 127.0.0.1 --port 1449 --strictPort`.
Create an equivalent local override when reproducing on a fresh checkout;
`.research` files are local evidence, not portable product configuration.

```powershell
New-Item -ItemType Directory -Force .research/dev/state | Out-Null
$env:OSG_DCS_BIOS_CONFIG = Join-Path (Get-Location) '.research/dev/state/dcs-bios.json'
$env:WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS = '--remote-debugging-port=9339'
pnpm tauri dev --no-watch --config .research/dev/tauri.json
```
