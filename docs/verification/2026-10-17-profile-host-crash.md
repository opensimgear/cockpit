# Active unified Host process crash

The new case in `tests/e2e/profile-acceptance.mjs` is **CI-pending**. It has not been run locally: another native gateway service would compete with the existing Cockpit development owner. This document specifies its exact oracle; it does not report a successful service crash run.

The preceding graceful Pause/Stop/restart case is retained. The new lifecycle re-applies the saved, natively pinned RGB Setter through the ordinary service and independently running production-C gateway/peripheral. Before death it requires actual `445566` readback, an owned positive endpoint lease with captured fallback `112233`, the running native owner, and the durable active ProfileSession journal containing its sealed cleanup receipt. The output-only module remains configured disabled and unpublished, with unchanged configuration/descriptor/flash counters.

The test sends `SIGKILL` directly to the active service child and requires an actual signal exit. It sends no Stop, SIGTERM or graceful shutdown first. While that process is dead, read-only peripheral administration observes the real, unmodified 5000 ms firmware lease watchdog. The same positive lease must become unowned with `fallbackStatus: applied` and actual `112233`; neither a simulated clock advance nor a replacement Claim is used. The active journal bytes must remain unchanged.

The same service executable restarts with the same configuration directory and inherited CI DBus/SecretService session. Before gateway reconnection, the test requires exact `recovery-needed`, null owner/applied snapshot, unchanged journal bytes, rejected inspection of the old owner, and a recovery-required rejection of Apply. It reconnects the same still-running gateway and requires the original exact gateway epoch, module node/CAN lease/boot/configuration generation and unchanged disabled publication. Read-only catalogue refresh precedes explicit Recover.

Recover must clear the journal and leave a stopped, ownerless session with no applied snapshot. Actual readback must retain the same retired endpoint lease, applied captured fallback and `112233`. A repeated Recover and one full advertised lease period of passive readback must produce no replacement Claim or productive output reactivation. The saved profile, persistent device configuration, descriptor, reconnect and flash counters remain unchanged. The test retains sanitized public route, ownership, native status, signal-exit and journal-hash checkpoints in the fixture's `active-crash.json`; sealed bytes/private credentials are not copied into that result.

This case, when it passes in CI, establishes watchdog restoration while the active SIGKILLed Host is dead and cold, explicit cleanup-only recovery after that observed expiry, using actual native processes and production-C protocol simulation. It does not establish release of a still-active lease after restart, an active HID-publication override, held-input/macro replay handling, physical CAN/USB behavior, driver submission or real-game qualification. Separate native phase/journal, private owner/recovery, publication and fresh-input-baseline tests retain those software contracts. The older persistent-configuration writer SIGKILL in `tests/e2e/acceptance.mjs` is a different owner and is not counted as this ProfileSession crash proof.
